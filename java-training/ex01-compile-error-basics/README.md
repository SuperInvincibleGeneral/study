# 課題01: コンパイルエラーの読み方（難易度 ★☆☆☆☆）

## この課題のねらい
`javac` が出すエラーメッセージは「どこが」「なぜ」おかしいかをかなり正確に教えてくれる。
まずは **エラーメッセージを英語のまま読み、そこから検索キーワードを切り出す** 練習をする。

## 状況
`work/Greeting.java` は挨拶文と合計金額を扱うクラスだが、コンパイルが通らない。
壊れている箇所は 3 か所ある。

## 仕様（テストが期待する動き）
| メソッド | 期待する結果 |
|---|---|
| `greet("山田")` | `"こんにちは、山田さん"` |
| `calcTotal(120, 3)` | `360` |
| `describe(20)` | `"成人"` |
| `describe(19)` | `"未成年"` |

## 手順
1. `work/Greeting.java` を編集する（`solution/` は最後まで開かないこと）
2. テストを実行する
   ```
   ./run.sh 01          # Linux / macOS
   run.bat 01           # Windows
   ```
3. `[FAIL]` が 0 件になればクリア

## 制約
- `test/` と `common/` は編集しない
- メソッド名・引数・戻り値の型は変えない

## 自力で調べるためのポイント
- エラーは **上から1件目** だけを見る。1件目を直すと後続が消えることが多い。
- `Greeting.java:9: error: ';' expected` の読み方 …… `ファイル名 : 行番号 : error : 内容`
- 検索するときは **自分のファイル名・変数名を消して、エラー本文だけ** を検索窓に入れる。
  - ✕ `Greeting.java error incompatible types`
  - ○ `java incompatible types int cannot be converted to String`
- 日本語で出てこないときは英語のまま検索する。Java のエラー本文は英語のほうが情報量が多い。
