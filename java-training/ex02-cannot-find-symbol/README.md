# 課題02: cannot find symbol の4パターン（難易度 ★☆☆☆☆）

## この課題のねらい
新人が最も多く出会うコンパイルエラーが `cannot find symbol` である。
このエラーは **「その名前が見つからない」** としか言っておらず、原因は複数ある。
エラーメッセージ中の `symbol:` と `location:` の行を読んで原因を切り分けられるようになる。

## 状況
`work/ShoppingCart.java` はコンパイルが通らない。`cannot find symbol` が複数出る。
**原因はすべて同じではない。** 1件ずつ、なぜ「見つからない」のかを考えること。

## 仕様（テストが期待する動き）
| メソッド | 期待する結果 |
|---|---|
| `count()` | カゴに入っている商品数 |
| `addItem(String)` | 商品を1件追加（重複も許可） |
| `summary()` | `"りんご, みかん, ぶどう"` のようにカンマ+空白で連結。空なら `""` |
| `has(String)` | 入っていれば `true` |

## 手順
1. `work/ShoppingCart.java` を編集する
2. `./run.sh 02` （Windows は `run.bat 02`）
3. `[FAIL]` が 0 件になればクリア

## 制約
- `test/` と `common/` は編集しない
- 公開メソッドの名前・引数・戻り値の型は変えない

## 自力で調べるためのポイント
- エラーの下に出る `symbol:` の行に注目する。
  - `symbol: class List` なら「クラスが見つからない」→ 何が足りない？
  - `symbol: variable itms` なら「変数が見つからない」→ 宣言した覚えは？
  - `symbol: method length()` なら「そのメソッドは無い」→ **その型に何のメソッドがあるかは公式 Javadoc を見る**
- `List` に何ができるかは検索より **公式 Javadoc** が速い。`java 21 List javadoc` で検索し、
  `docs.oracle.com` のページを開いてメソッド一覧を眺める習慣をつけること。
- 「配列は `length`、String は `length()`、コレクションは `size()`」のように、
  **似ているのに違うもの** はまとめて覚えると強い。
