# 課題04: ArrayIndexOutOfBoundsException と off-by-one（難易度 ★★☆☆☆）

## この課題のねらい
コンパイルが通っても実行時に落ちるバグがある。ここでは
**実行時例外のスタックトレースを読み、「何行目で」「どんな値で」落ちたかを特定する** 練習をする。

## 状況
`work/ScoreBoard.java` はコンパイルは通るが、テストを実行すると例外が出たり答えが合わなかったりする。

## 仕様（テストが期待する動き）
| メソッド | 仕様 |
|---|---|
| `max()` | 最高点を返す。**得点が0件なら `IllegalStateException` を投げる** |
| `sumOfLast(n)` | 末尾から n 件の合計。n が件数を超えたら全件の合計 |
| `at(index)` | index 番目の得点。**範囲外なら例外ではなく `-1` を返す** |

## 手順
1. `work/ScoreBoard.java` を編集する
2. `./run.sh 04` （Windows は `run.bat 04`）

## 制約
- `test/` と `common/` は編集しない
- メソッドのシグネチャは変えない
- `try-catch` で例外を握りつぶして誤魔化さないこと（境界を正しく計算して解くこと）

## 自力で調べるためのポイント
- Java 9 以降の例外メッセージは親切になっている。
  `Index 5 out of bounds for length 5` は「長さ5の配列の5番目を触った」と言っている。
  **配列の添字は 0 から始まるので、最後の添字はいくつか？** をまず紙に書くこと。
- スタックトレースは **上から1行目が落ちた場所**。`at ScoreBoard.max(ScoreBoard.java:16)` の
  `:16` が行番号。まずそこを開く。
- 検索するときは自分の変数名を消す。
  - ✕ `scores ArrayIndexOutOfBoundsException`
  - ○ `java ArrayIndexOutOfBoundsException Index out of bounds for length 原因`
- 「1個ずれる」バグは **off-by-one error** という名前が付いている。名前を知っていると検索が一気に楽になる。
  分からない現象に出会ったら「この現象に名前は付いていないか？」と考える癖をつけること。
